## 4. 自动化规则配置

### 4.1 对话分配规则

| 分配策略 | 说明 |
|---------|------|
| **轮询分配** | 按顺序平均分配给在线客服 |
| **负载均衡** | 优先分配给当前对话最少的客服 |
| **技能路由** | 按标签匹配（如"技术问题"→技术客服） |
| **全量广播** | 所有在线客服都能看到，谁先接谁处理 |

### 4.2 SLA (服务等级协议) 配置

| 设置项 | 默认值 | 说明 |
|--------|-------|------|
| **首次响应时间** | 5 分钟 | 从访客发第一条消息到客服首次回复的最长时间 |
| **后续响应时间** | 10 分钟 | 后续消息交互的最长响应时间 |
| **总解决时间** | 2 小时 | 对话从开始到结束的最长时间 |
| **超时预警提前量** | 1 分钟 | 即将超时时提前多久通知客服 |

### 4.3 自动回复规则

| 规则类型 | 触发条件 | 示例 |
|---------|---------|------|
| **工作时间外** | 非工作日/非工作时段 | 自动回复："当前是非工作时间，我们会在工作日尽快回复您" |
| **关键词触发** | 消息包含特定关键词 | 访客说"退款" → 自动发送退款流程说明 |
| **长时间无响应** | 访客超过 30 分钟未说话 | 自动发送："请问还有其他问题吗？如果没有，对话将在 5 分钟后结束" |
