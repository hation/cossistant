| **US-A03** | 作为客服，我希望查看访客的基本信息与浏览历史，这样我能更有上下文地回答问题 | P0 | 1. 右侧边栏显示访客画像<br>2. 显示当前会话浏览轨迹<br>3. 显示历史对话摘要<br>4. 显示地理位置与设备信息 |

| ID | 用户故事 | 优先级 | 验收标准 |

### 2.2 对话列表 (左栏)

#### 2.2.1 列表项信息密度

| 信息项 | 说明 | 显示条件 |
|--------|------|---------|
| **访客头像** | 访客首字母或 Gravatar | 始终显示 |
| **访客名称** | 访客姓名或"匿名访客" | 始终显示 |
| **消息预览** | 最新消息前 30 字 | 始终显示 |
| **时间** | 最后消息时间（相对时间，如"5分钟前"） | 始终显示 |
| **未读计数** | 红色气泡显示未读消息数 | 未读 > 0 时显示 |
| **状态标签** | 🟢 AI 处理中 / 🟡 等待人工 / 🔴 已超时 / ✅ 已结束 | 始终显示 |
| **优先级标记** | 🔥 高优先级（如 VIP 客户、重复咨询） | 满足条件时显示 |

#### 2.2.2 排序与筛选

**默认排序规则**（按优先级从高到低）：
1. SLA 即将超时的对话
2. 等待人工回复超过 5 分钟的对话
3. VIP 客户的对话
4. 新创建的对话
5. 最后消息时间（倒序）

**筛选器**：
- 按状态筛选：全部 / 待处理 / 进行中 / 已结束
- 按分配筛选：我的对话 / 未分配 / 全团队
- 按标签筛选：可自定义标签（如"售后问题"、"技术咨询"）
- 搜索：按访客姓名、邮箱、消息内容搜索

### 2.3 对话内容区域 (中栏)

#### 2.3.1 消息显示增强

| 功能 | 说明 | 优先级 |
|------|------|--------|
| **AI 消息标记** | AI 自动回复的消息显示"🤖 AI 回复"标签，客服可编辑或撤销 | P0 |
| **内部备注** | 客服可添加仅内部可见的备注（黄色背景，访客不可见） | P1 |
| **消息编辑** | 客服发送的消息在 5 分钟内可编辑，编辑后显示"已编辑"标记 | P2 |
| **消息撤回** | 客服发送的消息在 2 分钟内可撤回 | P2 |
| **快捷操作菜单** | 右键消息可操作：引用、复制、标记为常见问题 | P1 |

#### 2.3.2 AI 智能建议

**触发时机**：访客发送新消息后 1 秒内

**建议内容**：
1. **知识库匹配回答**：基于向量检索的最相关知识库内容
2. **历史相似回答**：过去客服对相似问题的回答
3. **多语言翻译**：如访客使用非预设语言，提供翻译建议

**交互设计**：
- 建议卡片显示在输入框上方
- 点击建议 → 直接填入输入框
- 悬停显示完整内容
- 支持快捷键：Cmd + 1/2/3 快速选择

#### 2.3.3 快捷回复系统

**两级快捷回复**：

| 层级 | 范围 | 管理权限 | 使用场景 |
|------|------|---------|---------|
| **个人快捷回复** | 仅当前客服可见 | 客服自己管理 | 个人常用语、个性化回复 |
| **团队快捷回复** | 组织内所有客服可见 | Admin 管理 | 公司标准回复、合规话术 |

**快捷回复触发**：
- 输入 "/" 弹出快捷回复菜单
- 支持模糊搜索（按关键词、标题）
- 支持变量插入（如 `{{访客姓名}}`、`{{公司名称}}`）

## 3. 协作功能

### 3.1 对话转接

**转接流程**：
```
当前客服点击转接
    ↓
选择目标客服（显示在线状态与当前对话数）
    ↓
填写转接备注（选填，仅内部可见）
    ↓
目标客服收到转接通知
    ↓
目标客服接受 → 对话转移
目标客服拒绝 → 对话返回原客服
```

**批量转接**：客服下班时可一键将所有进行中对话转给同事或公共池

### 3.2 内部邀请（专家加入）

**需求描述**：当客服遇到无法解决的技术问题时，可以邀请技术专家加入对话

**实现方式**：
- 专家以"隐身模式"加入，访客看不到专家存在
- 专家可查看对话历史、发送内部建议
- 客服与专家的交流对访客不可见
- 客服可以选择将专家的建议发送给访客

## 4. 个人工作区

### 4.1 在线状态管理

| 状态 | 说明 | 新对话分配 |
|------|------|-----------|
| 🟢 **在线** | 正常工作中 | 自动分配 |
| 🟡 **忙碌** | 正在处理紧急问题，暂时不接新对话 | 不分配 |
| 🔴 **离开** | 暂时离开工位（如午休） | 不分配，已有对话自动转给他人 |
| ⚫ **离线** | 已下班 / 未登录 | 不分配 |

### 4.2 个人绩效面板

**实时显示指标**：
- 今日接待对话数
- 平均首次响应时间
- 平均解决时长
- 今日满意度评分

## 5. 通知系统

### 5.1 通知类型与渠道

| 通知类型 | 浏览器通知 | 声音提醒 | 桌面弹窗 | 邮件通知 |
|---------|-----------|---------|---------|---------|
| 新对话分配 | ✅ | ✅ | ✅ | ❌ |
| SLA 即将超时 | ✅ | ✅ (更急促) | ✅ | ❌ |
| 对话被转接给我 | ✅ | ✅ | ✅ | ❌ |
| 访客发送新消息（非当前对话） | ✅ | ✅ | ✅ | ❌ |
| 被@提及（内部备注） | ✅ | ✅ | ✅ | ✅ |
| 每日日报 | ❌ | ❌ | ❌ | ✅ |

### 5.2 免打扰设置

- 支持设置专注时段（如每小时前 45 分钟不通知）
- 支持自定义声音提示（不同事件不同音效）
- 支持浏览器通知权限检测与引导
