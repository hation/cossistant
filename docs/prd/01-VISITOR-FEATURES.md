**所属模块**: 访客端 Widget
**优先级**: P0 (核心)
**版本**: v1.0

## 1. 用户故事 (User Stories)

### 1.1 核心对话场景

| ID | 用户故事 | 优先级 | 验收标准 |
|----|---------|--------|---------|
| **US-V01** | 作为网站访客，我希望在任意页面都能看到聊天入口按钮，这样我可以随时发起咨询 | P0 | 1. 所有页面右下角显示悬浮聊天按钮<br>2. 按钮不遮挡页面核心内容<br>3. 按钮支持自定义位置与样式 |
| **US-V02** | 作为网站访客，我希望打开聊天时看到欢迎语，这样我能快速了解可以获得什么帮助 | P0 | 1. 首次打开显示欢迎消息（可配置）<br>2. 支持显示常见问题快捷按钮<br>3. 显示客服在线状态 |
| **US-V03** | 作为网站访客，我希望发送消息后能即时收到回复，这样我的问题可以快速得到解答 | P0 | 1. 消息发送状态实时反馈（发送中/已送达/已读）<br>2. AI 回复延迟 < 2 秒<br>3. 支持"对方正在输入..."状态提示 |
| **US-V04** | 作为网站访客，我希望 AI 无法解决时可以转接人工客服，这样我的复杂问题能得到专业处理 | P1 | 1. AI 明确告知将转接人工<br>2. 显示当前排队位置与预计等待时间<br>3. 支持访客取消等待并继续与 AI 对话 |

### 1.2 访客体验增强

| ID | 用户故事 | 优先级 | 验收标准 |
|----|---------|--------|---------|
| **US-V05** | 作为网站访客，我希望可以上传截图或文件来说明问题，这样客服能更准确理解我的需求 | P1 | 1. 支持图片上传（PNG, JPG, GIF, 最大 10MB）<br>2. 支持常见文档（PDF, DOCX, XLSX, 最大 20MB）<br>3. 上传过程显示进度条<br>4. 上传失败可重试 |

## 2. 功能详细需求

### 2.1 聊天 Widget 核心交互

#### 2.1.1 启动按钮 (Launcher)

| 需求项 | 详细说明 | 优先级 |
|--------|---------|--------|
| **默认样式** | 圆形悬浮按钮，位于页面右下角，距离底部 20px，距离右侧 20px | P0 |
| **自定义样式** | 支持配置：<br>- 按钮颜色（主色）<br>- 按钮图标（内置 5+ 图标可选）<br>- 按钮文字（可选，如"需要帮助？"）<br>- 按钮形状（圆形 / 圆角矩形） | P1 |
| **行为** | 点击展开聊天窗口，再次点击收起；支持键盘快捷键（Alt+C）触发 | P0 |
| **在线状态指示** | 按钮边缘显示状态指示器：<br>- 🟢 绿色：客服在线<br>- 🟡 黄色：仅 AI 在线<br>- 🔴 灰色：完全离线 | P1 |

#### 2.1.2 聊天窗口 (Chat Window)

| 需求项 | 详细说明 | 优先级 |
|--------|---------|--------|
| **窗口尺寸** | 默认：380px（宽）x 600px（高）；支持响应式，移动端占满屏幕宽度 | P0 |
| **窗口头部** | 显示：<br>- 公司 Logo（可配置）<br>- 标题（可配置，如"客户支持"）<br>- 在线状态标签<br>- 最小化/关闭按钮 | P0 |
| **欢迎消息** | 支持富文本配置，可包含：<br>- 欢迎语<br>- 2-5 个常见问题快捷按钮<br>- 预计响应时间提示 | P0 |
| **消息气泡** | - AI 消息：左侧气泡，品牌主色调<br>- 访客消息：右侧气泡，强调色<br>- 客服消息：左侧气泡，带有客服头像与姓名<br>- 系统消息：居中灰色文字（如"已转接至人工客服"） | P0 |
| **输入框** | - 占位提示："输入消息..."<br>- 支持多行输入（Shift+Enter 换行）<br>- 表情按钮（😊）<br>- 附件按钮（📎）<br>- 发送按钮（Enter 或点击） | P0 |

#### 2.1.3 消息状态反馈

**消息生命周期状态机**：

```
发送中 → 已送达 → 已读
   ↓
发送失败（显示重试按钮）
```

| 状态 | 视觉反馈 | 触发条件 |
|------|---------|---------|
| **发送中** | 消息气泡半透明，右侧显示加载动画 | 访客点击发送后立即显示 |
| **已送达** | 消息气泡正常显示，右侧显示单勾 ✓ | 服务端确认接收消息 |
| **已读** | 双勾 ✓✓，蓝色高亮 | 客服/AI 已读取该消息 |
| **发送失败** | 消息边框红色，右侧显示重试图标 🔄 | 网络错误或服务端异常 |

### 2.2 实时对话功能

#### 2.2.1 打字状态同步

**需求描述**: 当客服/AI 正在输入回复时，访客端实时显示"对方正在输入..."

**交互细节**：
- 位置：输入框上方，左侧显示
- 样式：三个跳动圆点 + 文字
- 延迟策略：客服开始输入 500ms 后显示，停止输入 1000ms 后消失（避免频繁闪烁）
- 访客侧输入状态不上传给客服

#### 2.2.2 消息已读回执

**需求描述**: 访客可以知道自己发送的消息是否已被客服读取

**边缘情况处理**：
- AI 自动回复的消息：立即标记为"已读"（因为 AI 已处理）
- 离线留言：显示"已送达，客服将在上线后查看"

### 2.3 文件上传能力

| 文件类型 | 最大大小 | 预览能力 | 优先级 |
|---------|---------|---------|--------|
| **图片** | PNG, JPG, JPEG, GIF, WebP → 10MB | 聊天窗口内直接预览 | P0 |
| **文档** | PDF, DOCX, XLSX, PPTX → 20MB | 显示文件名 + 大小 + 下载图标 | P1 |
| **其他** | TXT, ZIP, CSV → 50MB | 显示通用文件图标 | P2 |

**上传流程**：
1. 访客点击附件按钮 → 打开系统文件选择器
2. 选择文件 → 本地校验类型与大小
3. 校验通过 → 显示上传进度条
4. 上传完成 → 文件预览插入聊天窗口
5. 上传失败 → 显示错误原因 + 重试按钮

### 2.4 访客身份识别与追踪

#### 2.4.1 匿名访客追踪

**需求描述**: 即使访客未登录，系统也能持续追踪其行为

**追踪标识符优先级**：
1. Cookie (localStorage) → 30 天有效期
2. 浏览器指纹（User Agent + 屏幕分辨率 + 时区等）→ 兜底方案
3. IP 地址 → 最粗粒度

#### 2.4.2 访客信息收集（渐进式）

| 收集时机 | 收集字段 | 是否必填 | 说明 |
|---------|---------|---------|------|
| **首次对话** | 无 | - | 零门槛开始聊天 |
| **转接人工时** | 姓名、邮箱 | 否（可跳过） | 方便后续跟进 |
| **离线留言** | 姓名、邮箱、消息 | 是（姓名 + 邮箱必填） | 确保能联系到访客 |
| **深度集成** | 用户 ID、邮箱、会员等级等 | 可选 | 通过 JS API 传入登录态 |

## 3. 用户体验 (UX) 需求

### 3.1 性能指标

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| **Widget 加载时间** | < 500ms（首次加载）<br>< 100ms（缓存后） | Lighthouse Performance |
| **消息发送响应** | < 200ms（从点击发送到显示"已送达"） | 前端埋点 |
| **AI 首条回复** | < 2 秒（95% 分位） | 后端监控 |
| **打字状态同步延迟** | < 500ms | 端到端测试 |

### 3.2 可访问性 (A11y)

| 需求项 | 说明 | 优先级 |
|--------|------|--------|
| **键盘导航** | 完整支持 Tab 键导航、Enter 触发操作、Esc 关闭窗口 | P1 |
| **屏幕阅读器** | ARIA 标签完整，支持 NVDA、VoiceOver、JAWS | P2 |
| **色彩对比度** | 符合 WCAG 2.1 AA 标准（文本与背景对比度 ≥ 4.5:1） | P1 |
| **字体缩放** | 支持浏览器 200% 字体缩放不破坏布局 | P2 |

### 3.3 多语言支持

| 需求项 | 说明 | 优先级 |
|--------|------|--------|
| **界面语言** | Widget 内置 10+ 语言包：中文（简/繁）、英文、日文、韩文、西班牙文、法文、德文、葡萄牙文、俄文、阿拉伯文 | P1 |
| **自动检测** | 根据浏览器 `navigator.language` 自动切换界面语言 | P1 |
| **手动切换** | 访客可在聊天窗口设置中切换语言 | P2 |
| **RTL 支持** | 阿拉伯文等从右向左语言的完整布局适配 | P3 |

## 4. 埋点与数据采集

### 4.1 核心事件

| 事件名 | 触发时机 | 采集字段 |
|--------|---------|---------|
| `widget_loaded` | Widget 脚本加载完成 | `website_id`, `url`, `referrer`, `load_time_ms` |
| `widget_opened` | 访客点击打开聊天窗口 | `website_id`, `visitor_id`, `source` |
| `widget_closed` | 访客关闭聊天窗口 | `website_id`, `visitor_id`, `duration_sec` |
| `message_sent` | 访客发送消息 | `website_id`, `visitor_id`, `message_type`, `has_attachment` |
| `message_received` | 访客收到回复 | `website_id`, `sender_type` (ai/human), `response_time_ms` |
| `hand_off_requested` | 访客请求人工转接 | `website_id`, `visitor_id`, `conversation_id` |
| `offline_message_submitted` | 访客提交离线留言 | `website_id`, `has_email`, `has_phone` |

### 4.2 漏斗指标

**聊天转化漏斗**：
```
Widget 展示
    ↓ (打开率)
Widget 打开
    ↓ (发消息率)
发送第一条消息
    ↓ (回复率)
收到回复
    ↓ (解决率)
对话结束（标记为已解决）
```

## 6. 验收标准 (Acceptance Criteria)

### P0 必须满足

- [ ] Widget 在所有主流浏览器中正常加载与显示
- [ ] 访客可以发送文本消息并实时收到 AI 回复
- [ ] 消息状态（发送中/已送达/已读）正确显示
- [ ] 支持图片上传与预览
- [ ] 30 天内回访访客能看到历史对话记录

### P1 应该满足

- [ ] 支持客服正在输入状态显示
- [ ] 支持人工转接与排队提示
- [ ] 离线留言功能可用
- [ ] 界面语言根据浏览器自动切换
- [ ] 完整键盘导航支持

### P2 可以考虑

- [ ] 文档上传（PDF/DOCX）支持
- [ ] 手动语言切换
- [ ] RTL 语言布局支持
