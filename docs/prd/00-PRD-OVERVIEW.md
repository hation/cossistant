## 1. 产品概述

### 1.1 产品定位

**Cossistant** 是一款面向中小企业的 AI 驱动智能客服 SaaS 平台，通过大语言模型技术实现 7x24 小时自动化客户对话、智能知识库检索、访客行为追踪与归因分析，帮助企业降低客服成本、提升客户满意度、挖掘销售转化机会。

### 1.2 核心价值主张

| 用户角色 | 核心痛点 | 产品价值 |
|---------|---------|---------|
| **企业主/管理者** | 客服人力成本高、夜间无人响应、服务质量难以量化 | 降低 60% 人工客服成本、全天候服务、数据化服务质量看板 |
| **客服团队** | 重复问题占用大量精力、新客服上手慢、多渠道切换麻烦 | AI 自动回复 80% 常见问题、智能知识库辅助回答、统一工作台 |
| **网站访客** | 工作时间外找不到客服、问题描述复杂、等待回复时间长 | 即时智能响应、多轮对话理解、无缝切换人工客服 |

### 1.3 目标用户画像

#### 🔵 核心用户群：SaaS 与互联网企业（50-500 人）
- **典型客户**: B2B SaaS 公司、电商平台、在线教育机构
- **需求特征**: 高并发咨询、知识库复杂、重视数据隐私与定制化
- **付费意愿**: 高（Pro 计划主力用户）

#### 🟢 重要用户群：中小企业（10-50 人）
- **典型客户**: 本地服务商家、小型电商店主、内容创作者
- **需求特征**: 快速上线、易用性优先、预算有限
- **付费意愿**: 中（Hobby 计划主力用户）

#### ⚪ 潜力用户群：个人开发者与创业团队（1-10 人）
- **典型客户**: 独立开发者、初创项目、开源项目
- **需求特征**: 免费试用、基础功能够用即可
- **付费意愿**: 低（Free 计划，潜在转化）

## 2. 产品愿景与目标

### 2.1 长期愿景

> **成为中小企业首选的 AI 客服基础设施，让每一家企业都能轻松拥有世界级的客户服务能力**

### 2.2 12 个月目标 (OKR)

**Objective 1: 产品市场匹配 (PMF)**
- KR1: 付费客户数达到 500+
- KR2: 月经常性收入 (MRR) 达到 $50K+
- KR3: 客户留存率 (NDR) > 110%
- KR4: NPS 评分 > 50

**Objective 2: AI 能力领跑行业**
- KR1: AI 首条回复解决率 > 80%
- KR2: 平均对话时长降低 40%
- KR3: 知识库覆盖率 > 95%
- KR4: 人工介入率 < 20%

**Objective 3: 开发者生态建设**
- KR1: API 调用量 > 100 万次/月
- KR2: 第三方集成数量 > 20+
- KR3: 开源社区 Star > 2000

## 4. 用户角色与权限矩阵

| 角色 | 层级 | 核心权限 | 典型使用者 |
|------|------|---------|-----------|
| **Owner (所有者)** | 组织级 | 完整权限（删除组织、修改计费、管理 Owner） | 企业创始人、CTO |
| **Admin (管理员)** | 组织级 | 团队管理、设置修改、查看所有数据 | 运营总监、客服主管 |
| **Agent (客服)** | 网站级 | 接待对话、查看访客、管理自己的快捷回复 | 一线客服人员 |
| **Viewer (观察员)** | 网站级 | 只读权限（查看对话、报表，不可操作） | 投资人、外部顾问 |

## 5. 术语表

| 术语 | 定义 |
|------|------|
| **Organization (组织)** | 客户公司主体，可包含多个网站 |
| **Website (网站)** | 单个接入客服的网站/应用，独立配置与数据隔离 |
| **Visitor (访客)** | 访问网站并发起对话的终端用户 |
| **Conversation (对话)** | 访客与客服/AI 之间的一次完整交互会话 |
| **Message (消息)** | 对话中的单条消息（文本、图片、文件） |
| **Knowledge Base (知识库)** | 企业知识文档集合，用于 AI 检索回答 |
| **SLA (服务等级协议)** | 客服响应时间的量化承诺指标 |
| **First Response Time (FRT)** | 首次响应时间，从访客发第一条消息到客服回复的时间 |
| **Resolution Time (RT)** | 问题解决时间，对话从开始到结束的总时长 |
| **Hand-off (人工转接)** | AI 无法解决时，将对话转交给真人客服的过程 |
