## 2. AI 自动回复引擎

### 2.1 回复策略

| 策略 | 说明 | 触发条件 |
|------|------|---------|
| **知识库匹配** | 直接引用知识库已有内容 | 问题与知识库匹配度 > 85% |
| **澄清式提问** | AI 不清楚时，引导访客提供更多信息 | 知识库匹配度 60-85%，问题语义模糊 |
| **转接人工** | AI 明确表示无法处理，建议转接人工 | 知识库匹配度 < 60%，或问题涉及人工操作 |

### 2.2 多轮对话上下文理解

**上下文窗口**：最近 10 条消息（双向：访客 + AI）

**上下文利用**：
- 实体继承（如访客提到"我的订单 12345"，后续对话自动引用该订单号）
- 指代消解（正确理解"它"、"这个"等指代）
- 话题切换检测（识别访客切换话题时重置部分上下文）

### 2.3 人工介入判断

**自动转接场景**：
- 访客明确要求人工客服（如"我要找真人"）
- AI 连续 3 轮无法给出满意答案
- 检测到访客负面情绪（如"你们的服务太烂了"）
- 涉及敏感操作（如退款、账号注销）

## 3. 知识库智能管理

### 3.1 内容自动提取

**来源**：客服手动标记为"常见问题"的对话

**提取流程**：
1. 客服在对话中标记某条消息为优质回答
2. AI 自动提取问题（访客侧）+ 答案（客服侧）
3. 生成知识库草稿，包含：
   - 问题标题（自动生成）
   - 多个变体问法
   - 标准回答
4. 管理员审核后正式入库

### 3.2 知识澄清（Knowledge Refinement）

**场景**：AI 回答后访客表示不满意或不理解

**处理流程**：
```
访客："这不是我想要的答案"
    ↓
AI："抱歉，请告诉我您具体想了解什么？"
    ↓
访客进一步说明问题
    ↓
AI："谢谢，根据您的补充..."（重新回答）
    ↓
后台自动记录：原问题 → 用户反馈 → 澄清后问题 + 回答
    ↓
定期自动更新知识库，覆盖原问答
```

### 3.3 知识库质量评估

**自动评估指标**：
- 命中率：多少问题成功匹配到知识库
- 解决率：匹配后访客是否满意（是否继续追问）
- 覆盖率：多少常见问题已有对应知识

## 4. AI 辅助客服功能

### 4.1 智能建议回复

见客服工作台文档 2.3.2 节

### 4.2 对话自动摘要

**生成时机**：
- 对话结束时自动生成摘要
- 对话转接时生成给下一位客服的摘要

**摘要内容结构**：
```
【访客问题】：简述访客核心诉求（1-2 句）
【处理过程】：已采取的措施与解答
【待跟进事项】：未解决的问题或需要继续处理的点
【客户情绪】：正面 / 中性 / 负面
```

### 4.3 智能标签建议

**自动为对话打标签**，基于：
- 关键词匹配（预设标签库）
- 语义分类（无监督聚类发现新类别）
- 客服手动打标签的历史行为学习

## 5. AI 模型配置

### 5.1 多模型支持

| 模型提供商 | 典型模型 | 适用场景 |
|-----------|---------|---------|
| **OpenAI** | GPT-4o / GPT-4 Turbo | 主力模型，高质量生成 |
| **OpenAI** | GPT-3.5 Turbo | 低成本场景，摘要/分类 |
| **Anthropic** | Claude 3 Opus | 长文档处理、复杂推理 |
| **Anthropic** | Claude 3 Sonnet | 平衡性能与成本 |

### 5.2 Fallback 机制

**降级策略**：
```
主模型 (如 GPT-4)
    ↓ 超时/失败
备用模型 (如 GPT-3.5)
    ↓ 超时/失败
静态模板回复（不调用 AI，直接返回预设话术）
```
