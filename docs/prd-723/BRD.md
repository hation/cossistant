## 1. 项目背景

### 1.1 市场问题

SaaS 团队面临三大客户支持痛点：
1. 重复问题占用客服 60% 以上时间，人力成本高
2. 传统客服工具集成成本高，与现有系统数据打通困难
3. AI 客服产品普遍是黑盒方案，无法深度定制、自托管

### 1.2 商业机会

开发者优先的可嵌入客户支持平台，核心差异化：
- **无头架构**：API + 可嵌入 Widget，不强制使用特定前端
- **实时优先**：WebSocket 全链路实时通信，无轮询延迟
- **AI 原生**：从设计上集成大语言模型，不是事后附加功能
- **自托管友好**：完整自部署能力，数据完全可控

### 1.3 商业目标（3 年）

| 目标 | 指标 | 时间范围 |
|------|------|---------|
| **收入目标** | ARR $1M | 第 1 年 |
| **客户获取** | 付费网站 1000 个 | 第 1 年 |
| **产品粘性** | 月活跃度 > 80% | 持续 |
| **自托管生态** | 自部署实例 500+ | 第 2 年 |

## 3. 商业模式

### 3.1 三级订阅计划（按网站计费）

| 计划 | 定价 | 目标客户 | 核心限制 |
|------|------|---------|---------|
| **Free** | $0 | 开发者试用、小流量站点 | 20 对话/月、200 消息/月、1 个团队席位、30 天对话保留 |
| **Hobby** | $20/月（促销）常规 $40/月 | 独立开发者、小产品 | 无限对话/消息、2 个团队席位、永久保留、AI 信用 1000/月 |
| **Pro** | $40/月（促销）常规 $80/月 | 成长型公司、产品团队 | 无限对话/消息、4 个团队席位、AI 信用 3000/月、高级集成、自带模型 Key |

### 3.2 收入杠杆

1. **网站数量扩展**：一个组织多个网站 = 多个订阅
2. **AI 信用超量**：Pro 客户超出 3000 信用后按量付费（$0.01/credit）
3. **团队席位增购**：超出基础席位后 $15/席位/月
4. **企业版**：未来（自定义部署、SLA 保障、专属支持）

### 3.3 自托管策略

自托管完全免费，核心商业考量：
- 获取开发者社区口碑
- 大公司先内部试用，再转化为云托管企业版
- 生态锁定：自托管用户产生的插件、集成反哺云版本

## 4. 财务预测

### 4.1 获客成本预估

| 渠道 | CPA | 占比 |
|------|-----|------|
| **开源社区** | $0 | 40% |
| **内容营销** | $50 | 30% |
| **开发者平台** | $100 | 20% |
| **付费广告** | $200 | 10% |
| **加权平均** | $54 | - |

### 4.2 LTV 计算

**假设**：月流失率 4% → 客户生命周期 25 个月
- Free → Hobby 转化率 5%，LTV = $20 × 25 = $500
- Hobby → Pro 转化率 20%，LTV = $40 × 25 = $1000
- 平均 LTV ≈ $600

**LTV/CAC 比值 = 600/54 ≈ 11.1，具备健康的盈利空间**

## 5. 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| Polar 计费平台故障 | 高 | 中 | 架构已实现多级降级、停电模式，硬限制自动关闭 |
| AI 成本超支 | 高 | 中 | AI Credit 计量、按 Token 精确计费、可配置模型降级 |
| 获客速度低于预期 | 中 | 高 | 开源社区驱动、产品主导增长、自托管免费扩大影响力 |
| 大厂推出同类产品 | 高 | 低 | 差异化：自托管 + 开发者优先 + API 驱动 |
