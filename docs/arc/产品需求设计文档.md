
 **中间模型** | Kimi V2.5 (带思考), Kimi V2.6 | Hobby+ | 思考功能额外收费，停电模式可用 |

**模型切换**：
- 每个AI代理可独立配置模型
- 可随时切换，不影响现有对话
- 不同模型消耗不同AI信用额度

#### 5.7.2 提示词配置

**可配置提示词**：

#### 5.8.2 AI信用额度计费

**四维定价公式**：

```
总信用 = 基础运行费(1) + 模型附加费 + 思考附加费 + 工具调用费
```

**详细说明**：

| 费用项 | 计算方式 | 说明 |
|--------|---------|------|
| **基础运行费** | 固定1信用 | 每次AI处理消息的基础费用 |
| **模型附加费** | 因模型而异 | Kimi V2.6=0.5, GPT-5.2=1, GPT-5.5=3.5 |
| **思考附加费** | 开启思考功能加收 | Kimi V2.5=0.5, GPT-5.5=3 |
| **工具调用费** | max(0, (收费工具数-2) × 0.5) | 前2个工具免费，超出后每个0.5 |

**不计费工具列表**（前2个免费后仍不计费的内置工具）：
- sendMessage, sendFollowUpMessage, sendAcknowledgeMessage
- escalate, resolve, markSpam, skip
- aiDecision, respond, loadSkill

#### 5.8.3 硬限制执行

**滚动30天窗口限制**：

```
窗口起始时间 = 当前时间 - 30天
统计窗口内对话数和消息数
→ 达到上限时，新对话自动锁定
→ 仪表板显示超限警告
→ 提示用户升级计划
```

**按创建时间截止**：
- 排序窗口内所有对话，取第N个对话的时间作为截止点
- 截止点之前的对话保留，之后的全部锁定

#### 5.8.4 故障降级策略

**停电模式（Outage Mode）**：

当计费平台不可用时：
- 仅允许使用基础模型（DeepSeek V4 Pro, Kimi V2）
- 暂停AI信用额度计量
- 暂停硬限制执行
- 高级模型用户收到降级提示

**缓存降级**：
- 计划信息缓存10秒
- 失败时使用陈旧数据（最多1分钟）
- 仍失败则降级到Free计划功能
