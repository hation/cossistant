## 四、自托管（Self-Hosted）特殊权益

```
🌟 自托管 = Pro计划 + 全部解锁 + 完全免费
```

| 权益项 | 自托管值 | 说明 |
|-------|---------|------|
| **所有boolean功能** | ✅ 全部开启 | 没有任何功能开关限制 |
| **所有数值限制** | ♾️ 无限 | 对话/消息/联系人全部无限制 |
| **训练间隔** | 0分钟（即时） | 内容更新立即重新训练 |
| **硬限制执行** | ❌ 关闭 | 不会因为超量锁定任何对话 |
| **AI信用计费** | ❌ 禁用 | 可自由对接自己的LLM API |

> **产品策略洞察**：这是典型的 **"开源免费，云服务收费"** 模式。通过开源吸引开发者生态，通过托管服务解决运维、可靠性、计费等痛点。

## 五、故障降级与停电模式（隐藏的产品设计亮点）

| 触发条件 | 降级策略 | 用户感知 |
|---------|---------|---------|
| **Polar API 连续失败** | 1. 暂停硬限制执行<br>2. 仅允许基础模型<br>3. 暂停AI信用计费 | 用户不会因为计费平台故障而失去服务 |
| **Redis 缓存失效** | 使用内存陈旧缓存回退 | 完全透明，用户无感知 |
| **计划信息超时10秒** | 降级到默认Free计划配置 | 显示"正在同步订阅信息"提示 |

> **产品思维**：这不是一个技术细节，而是 **核心产品可靠性承诺**——"即使我们的计费系统挂了，你的客服也不会中断"。

## 七、定价体系的3个产品创新点

### 🎯 创新点1：AI信用四维计费模型

**不是简单按Token计费**，而是区分四个维度，更公平地反映AI实际工作复杂度：
- 基础运行费（固定门槛）
- 模型等级费（模型越好越贵）
- 思考深度费（推理思考额外收费）
- 工具调用费（使用能力越多越贵）

这比行业通行的"按消息数计费"或"按Token计费"更精细化，也更合理。

---

### 🎯 创新点2：按网站独立计费策略

**拒绝常见的"组织级订阅共享"**，强制每个网站独立订阅：
- 本质是更好的多租户隔离
- 收入放大策略：一个客户多个网站 = 多份订阅收入
- 避免了"一个订阅服务全公司"的收入稀释问题

这与Intercom等传统客服产品按"客服席位"计费形成鲜明对比。

---

### 🎯 创新点3：停电模式可靠性承诺

**把"计费平台故障时怎么办"从一个技术问题变成一个明确的产品承诺**：
- 建立开发者信任："我们不会因为自己的问题让你下线"
- 差异化竞争点：这是所有SaaS产品应该做但几乎没人做的
- 本质是"客户成功优先于收入保证"的产品价值观

## 附录：关键技术选型与产品意义

| 组件 | 技术选择 | 产品意义 |
